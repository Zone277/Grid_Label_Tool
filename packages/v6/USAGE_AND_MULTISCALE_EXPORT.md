# LabelTool v6 使用说明与多尺度导出说明

本文由 `tools/v6/README.md`、`tools/v6/AGGREGATION_MODES.md` 以及 `tools/v6/dist` 下对应文档聚合整理而成，仅保留两部分内容：工具使用说明和多尺度导出说明。

## 一、工具使用说明

### 1. 标注目标

LabelTool v6 面向布料多层区域和褶皱风险识别。人工标注始终在基础网格上完成，默认基础块为 `16×16` 像素，默认标签为四类：

```text
0 背景信息
1 单层布料
2 多层布料-无褶皱
3 多层布料-有褶皱
```

标签存在层级关系，不是互相独立的四个平面类别：

```text
0 背景
布料
  1 单层布料
  多层布料
    2 多层布料-无褶皱
    3 多层布料-有褶皱
```

### 2. 基本使用流程

1. 启动 `tools/v6/dist/enhanced_grid_label_tool.exe`。
2. 先选择图片文件夹，再选择输出文件夹，并填写标注员 ID。
3. 默认基础块为 `16×16`，可在界面中修改基础块宽高。首次产生标注后，基础块尺寸会锁定，避免同一批标注中混入不同网格尺寸。
4. 使用 `0/1/2/3` 切换当前标签。
5. 左键点击或拖动进行连续标注，右键拖动擦除为背景 `0`，`Shift+左键拖动` 可进行矩形区域填充。
6. `Space` 保存当前图片并切换到下一张，`Ctrl+S` 只保存当前图片。
7. 标注完成后，在多尺度导出区域设置核大小和步长，例如 `1:1,2:2,3:3,4:4`，选择聚合模式后执行导出。

画布不显示 `0,1[3]` 这类文本，只显示网格、颜色覆盖和选区边框。标签 `0` 默认透明，便于查看背景区域。

### 3. 默认快捷键

| 动作 | 默认键 |
|---|---|
| 上一张 / 下一张 | `Q` / `E` |
| 保存并下一张 | `Space` |
| 选择标签 | `0` / `1` / `2` / `3` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 减小 / 增大画笔 | `[` / `]` |
| 复制上一帧预览 | `C` |
| 确认 / 取消预览 | `Enter` / `Esc` |
| 适应窗口 | `F` |
| 放大 / 缩小 | `Ctrl++` / `Ctrl+-` |
| 保存但不切换 | `Ctrl+S` |

全部快捷键可在界面中自定义。个人快捷键配置保存到：

```text
%APPDATA%\LabelTool\v6\personal_config.json
```

该配置不写入项目数据，也不会覆盖其他标注员的键位。输入框获得焦点时，全局快捷键会暂停；`Space` 会被工具消费，不会触发当前获得焦点的按钮。

### 4. 标注保存与历史回读

按 `Space` 或 `Ctrl+S` 保存基础标注时，工具会先追加写入 JSONL；正常退出或切换输出目录时，再压缩生成总 `annotations.json`：

```text
输出目录/
  annotations.json
  workers/{annotator_id}/annotations.jsonl
```

如果输入文件夹和输出文件夹都选择为一个数据集根目录，例如：

```text
C:\Users\50199\Desktop\Adi\labelTool\0_datasets
```

工具会扫描其一级子目录作为不同材质数据集：

```text
0_datasets/
  13/
    0.jpg
    annotations.json
    workers/{annotator_id}/annotations.jsonl
  14/
    0.jpg
    annotations.json
```

历史回读会自动读取各材质子目录中的 `annotations.json` 和 `workers/{annotator_id}/annotations.jsonl`，并映射为界面中的根目录相对路径，例如：

```text
13/0.jpg
14/0.jpg
```

因此可以直接在 `0_datasets` 根目录下查看、修改已有标注，并继续进行多尺度导出，不需要把所有材质图片合并到同一个文件夹。

## 二、多尺度导出说明

### 1. 多尺度导出的目的

人工只需要在细粒度基础网格上标注一次，例如 `16×16`。后续可通过多尺度聚合重复导出不同物理尺寸的数据，例如：

```text
1:1 -> 16×16
2:2 -> 32×32
3:3 -> 48×48
4:4 -> 64×64
```

这样可以在不重新标注的情况下，对比不同输入尺度对模型效果的影响，也可以为机械臂后续操作生成不同粒度的风险区域或候选操作区域。

### 2. 输出目录结构

单个标注目录导出时，结构如下：

```text
exports/
  balanced/
    kernel_3_stride_3_size_48x48/
      layer_4/0/
      layer_4/1/
      layer_4/2/
      layer_4/3/
      manifest.jsonl
      summary.json
  safety_first/
  precision_first/
```

如果输入目录是 `0_datasets` 这类数据集根目录，工具会保留材质维度：

```text
exports/
  balanced/
    kernel_3_stride_3_size_48x48/
      13/
        layer_4/0/
        layer_4/1/
        layer_4/2/
        layer_4/3/
      14/
        layer_4/0/
        layer_4/1/
        layer_4/2/
        layer_4/3/
      manifest.jsonl
      summary.json
```

`manifest.jsonl` 会记录每个切片的来源图片、材质 `dataset`、源相对路径 `source_relative_path`、窗口坐标、Padding 信息、聚合模式、阈值、标签和置信信息。`summary.json` 会记录总体类别统计，以及每个材质的样本数量和类别分布，方便后续按材质评估模型效果。

### 3. Padding 与有效面积

固定基础块后，原图右侧和下侧会补齐到基础块尺寸的整数倍：

```text
padded_width  = ceil(original_width  / base_width)  * base_width
padded_height = ceil(original_height / base_height) * base_height
pad_right     = padded_width  - original_width
pad_bottom    = padded_height - original_height
```

工具只在右侧和下侧使用镜像 Padding。镜像像素用于生成固定尺寸图像块，但不参与标签面积投票。

例如原图为 `650×481`，基础块为 `16×16`：

```text
padded_width  = ceil(650/16)*16 = 656
padded_height = ceil(481/16)*16 = 496
pad_right     = 6
pad_bottom    = 15
标签网格       = 41列 × 31行
```

右下角基础格虽然导出为完整 `16×16` 图像，但真实有效面积只有：

```text
real_width  = 650 - 40*16 = 10
real_height = 481 - 30*16 = 1
valid_area  = 10*1 = 10
valid_ratio = 10/256 = 3.90625%
```

其余镜像像素不计入 `A0/A1/A2/A3`，避免 Padding 被错误当作背景或重复布料。

### 4. 核大小与步长

核大小 `k` 表示一个粗尺度窗口包含 `k×k` 个基础格。步长 `s` 表示窗口每次滑动多少个基础格：

```text
1 <= s <= k
```

工具会按常规起点生成窗口：

```text
0, s, 2s, ... <= L-k
```

如果最后一个常规起点不等于 `L-k`，则追加 `L-k`，保证右边和下边不漏掉。

以 `640×480` 图片和 `16×16` 基础块为例：

```text
列数 C = 640/16 = 40
行数 R = 480/16 = 30
```

不同设置的窗口数量为：

```text
k=3, s=3 -> 140 个窗口
k=3, s=2 -> 300 个窗口
k=3, s=1 -> 1064 个窗口
```

核大小等于步长，例如 `2:2,3:3,4:4`：

- 样本基本不重叠，仅边缘贴边窗口可能重叠。
- 样本数量较少，训练速度较快。
- 相邻样本相关性较低。
- 适合作为不同物理尺度模型效果对比的基准。
- 缺点是空间边界较粗，容易将窗口边界处的小面积多层或褶皱区域预测为单层或背景。

步长小于核大小，例如 `3:1,4:2`：

- 同一区域会被多个窗口覆盖。
- 样本数量和磁盘占用显著增加。
- 能生成更密集的空间风险图，更适合机械臂定位区域边界。
- 训练样本高度重复，容易让测试指标虚高。
- 必须按原图或视频序列划分训练集和测试集，不能把同一原图的重叠窗口分到不同集合。

### 5. 分层面积投票

每个粗尺度窗口内，基础格按其真实有效像素面积加权：

```text
A0 = 背景真实有效面积
A1 = 单层布料真实有效面积
A2 = 多层无褶皱真实有效面积
A3 = 多层有褶皱真实有效面积
A  = A0 + A1 + A2 + A3
```

第一层判断是否主要包含布料：

```text
P_cloth = (A1 + A2 + A3) / A
```

如果 `P_cloth < T_cloth`，输出标签 `0`。

第二层只在布料区域中判断单层或多层：

```text
P_multi = (A2 + A3) / (A1 + A2 + A3)
```

如果 `P_multi < T_multi`，输出标签 `1`。

第三层只在多层区域中判断是否有褶皱：

```text
P_wrinkle = A3 / (A2 + A3)
```

如果 `P_wrinkle >= T_wrinkle`，输出标签 `3`，否则输出标签 `2`。

这种分层投票比简单四类多数票更符合标签层级关系。例如 16 个基础格中：

```text
标签1：7格
标签2：5格
标签3：4格
```

简单多数票会输出标签 `1`，但多层总面积为 `5+4=9` 格，实际更应判断为多层。

### 6. 四种聚合模式的区别

| 模式 | `T_cloth` | `T_multi` | `T_wrinkle` | 主要用途 |
|---|---:|---:|---:|---|
| `safety_first` 安全优先 | 0.25 | 0.30 | 0.15 | 机械臂风险区、禁止区、减速区 |
| `balanced` 平衡 | 0.50 | 0.50 | 0.30 | 模型训练、尺度对比、常规验证 |
| `precision_first` 精度优先 | 0.70 | 0.70 | 0.50 | 高纯度候选操作区、抓取点筛选 |
| `risk_priority` 最高风险优先 | 无 | 无 | 无 | 窗口内任意有效面积出现高风险标签即升级 |

`risk_priority` 不使用面积阈值，而是在有效原图面积中按 `3 > 2 > 1 > 0`
选择最高标签。Padding 区域即使镜像出标签也不参与升级。该模式表达“粗区域内
是否存在风险”，并不表达粗区域的主体状态；它通常提高标签 `2/3` 的召回并扩大
机械臂禁止区，但也会降低空间定位精度和高风险 precision。该模式必须作为独立
训练目标，不能与另外三种模式混入同一训练集。

#### 安全优先 `safety_first`

安全优先模式阈值最低，只要窗口中存在一定比例的布料、多层或褶皱，就更容易升级为风险类别。

对实验指标的影响：

- 标签 `2` 和 `3` 的召回率通常更高。
- 标签 `2` 和 `3` 的精确率可能下降。
- 背景和单层区域的误报会增加。
- 如果以标签 `2/3` 作为正类，漏检率会降低，但误报率会上升。

对后续检测的影响：

- 容易将背景预测为单层布料。
- 容易将单层布料预测为多层布料。
- 容易将多层无褶皱预测为多层有褶皱。
- 风险区域会被扩大，适合机械臂避障、减速和禁止操作区生成。
- 不适合直接作为精确抓取点，因为会包含较多保守误报区域。

#### 平衡 `balanced`

平衡模式要求窗口中多数有效面积支持当前层级判断，是默认推荐的训练和尺度对比模式。

对实验指标的影响：

- 精确率和召回率相对均衡。
- 类别边界不会像安全优先那样明显扩张，也不会像精度优先那样明显收缩。
- 更适合作为比较 `16/32/48/64` 等不同物理尺度模型效果的基准。
- 通常更适合观察整体 Accuracy、Macro-F1、Weighted-F1 等常规指标。

对后续检测的影响：

- 相比安全优先，不太容易将单层预测为多层。
- 相比精度优先，不太容易将多层预测为单层或背景。
- 对褶皱保持一定敏感度，但单个小褶皱区域不一定会把整个窗口升级为标签 `3`。
- 适合作为常规模型输出或离线评估结果。

#### 精度优先 `precision_first`

精度优先模式阈值最高，只有窗口内部类别足够纯时才输出高风险类别。

对实验指标的影响：

- 标签 `2` 和 `3` 的精确率通常更高。
- 标签 `2` 和 `3` 的召回率可能下降。
- 边缘、多层面积较小或褶皱面积较小的窗口更容易被降级。
- 如果只看高风险类 precision，该模式可能表现更好；如果看高风险类 recall，可能表现更差。

对后续检测的影响：

- 容易将多层有褶皱预测为多层无褶皱。
- 容易将多层无褶皱预测为单层布料。
- 容易将布料边缘区域预测为背景。
- 输出区域更纯，更适合筛选机械臂候选抓取点或高置信接触区域。
- 不适合单独用于风险保护，因为可能漏掉面积较小的多层或褶皱区域。

### 7. 数值示例

假设一个 `4×4` 粗窗口包含 16 个等面积基础格：

```text
A0=2, A1=6, A2=7, A3=1
P_cloth   = 14/16 = 0.875
P_multi   = 8/14  = 0.5714
P_wrinkle = 1/8   = 0.125
```

输出结果：

```text
safety_first    -> 2
balanced        -> 2
precision_first -> 1
```

原因是精度优先要求 `P_multi >= 0.70`，该窗口多层占布料区域比例只有 `0.5714`，因此容易将多层窗口预测为单层。

再看另一个例子：

```text
A0=2, A1=4, A2=5, A3=5
P_cloth   = 14/16 = 0.875
P_multi   = 10/14 = 0.7143
P_wrinkle = 5/10  = 0.5
```

输出结果：

```text
safety_first    -> 3
balanced        -> 3
precision_first -> 3
```

该窗口在三层判断上都满足精度优先阈值，因此三种模式均输出标签 `3`。

再看第三个例子：

```text
A0=8, A1=4, A2=3, A3=1
P_cloth   = 8/16 = 0.5
P_multi   = 4/8  = 0.5
P_wrinkle = 1/4  = 0.25
```

输出结果：

```text
safety_first    -> 3
balanced        -> 2
precision_first -> 0
```

该例说明三种模式的目标不同：

- 安全优先更容易将少量褶皱区域预测为标签 `3`。
- 平衡模式会保留多层判断，但不会把褶皱比例不足的窗口升级为标签 `3`。
- 精度优先要求布料占比至少 `0.70`，因此容易将边缘布料窗口预测为背景。

### 8. 对训练、评估和检测的建议

- 模型尺度基准实验建议使用 `balanced`，并优先采用 `s=k`，例如 `1:1,2:2,3:3,4:4`。
- 机械臂风险保护建议额外导出 `safety_first`，用于生成多层和褶皱风险区。
- 机械臂候选抓取点筛选建议额外导出 `precision_first`，用于寻找更纯、更稳定的操作区域。
- 四种模式服务于不同目标，不应把不同模式的样本混在同一个训练集中。
- 使用重叠窗口时，应按原图或视频序列划分训练集和测试集，避免同一原图的高度相似窗口同时进入训练集和测试集导致指标虚高。
- 不同尺度和不同步长的样本数量差异较大，比较模型效果时应记录并控制采样数量，避免样本数量成为主要变量。
- 每次实验应记录基础块尺寸、核大小、步长、聚合模式、实际阈值、原图级数据划分和采样策略。
