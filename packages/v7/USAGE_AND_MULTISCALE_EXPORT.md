# LabelTool v7 使用说明与多尺度导出

本文只说明两部分：基础标注工具的使用，以及 v7 多尺度数据导出、训练索引和复原可视化。

## 一、标注工具使用

### 1. 标签定义

| 标签 | 含义 | 默认颜色 |
|---|---|---|
| `0` | 背景信息 | 灰色，画布覆盖透明 |
| `1` | 单层布料 | 绿色 |
| `2` | 多层布料-无褶皱 | 洋红 |
| `3` | 多层布料-有褶皱 | 红色 |

默认基础块为 `16×16`，默认多尺度规格为：

```text
1:1,2:2,3:3,4:4
```

分别表示核大小和步长，对应 `16×16`、`32×32`、`48×48`、`64×64`。

### 2. 基础标注流程

1. 启动 `enhanced_grid_label_tool.exe`。
2. 选择图片文件夹，再选择输出文件夹。
3. 确认基础块宽高。多人协作时所有标注员必须使用相同尺寸。
4. 使用数字键切换标签，在网格上点击、拖动或框选连续区域。
5. 按空格保存当前图片并切换到下一张。
6. 使用“估算数量”检查不同聚合模式在 Full 和 Sampled 中的四类数量。
7. 使用“开始导出”生成一个新的、带时间和配置签名的运行目录。

选择图片文件夹后，图片按相对路径的自然数字顺序加载。例如同一文件夹中的
`1.jpg`、`2.jpg`、`10.jpg` 会按 `1,2,10` 顺序出现，而不是按字典序排成
`1,10,2`。

基础标注仍以每张图片的 `annotations.json` 为事实来源。不要把多尺度 PNG 当作可继续编辑的人工标注。

### 3. 默认快捷键

| 动作 | 默认键 |
|---|---|
| 上一张 / 下一张 | `Q` / `E` |
| 保存并下一张 | `Space` |
| 选择标签 | `0` / `1` / `2` / `3` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 减小 / 增大画笔 | `[` / `]` |
| 复制上一帧标签预览 | `C` |
| 确认 / 取消操作 | `Enter` / `Esc` |
| 适应窗口 | `F` |
| 放大 / 缩小 | `Ctrl++` / `Ctrl+-` |
| 仅保存当前图片 | `Ctrl+S` |

所有快捷键均可在“个人快捷键设置”中修改。重复绑定会被阻止；输入框获得焦点时全局快捷键暂停；个人配置保存在：

```text
%APPDATA%\LabelTool\v7\personal_config.json
```

个人配置不写入协作数据，不会影响其他标注员。

### 4. 多材质与多人协作

输入根目录可以直接包含多个材质子目录。工具读取各子目录中的标注，导出时继续保留材质维度，无需先把图片合并到一个文件夹。

多人协作必须满足：

- 每张原图只分配给一名主标注员，避免无规则覆盖。
- 所有人使用同一项目清单、基础块尺寸和标签定义。
- 回传包中保留 `image_id`、原图相对路径和 SHA256。
- 合并前检查重复图片、哈希冲突和缺失图片。
- 快捷键属于个人配置，不参与项目合并。

## 二、多尺度导出

### 1. v7 输出结构

每次导出都创建新目录，旧结果不会混入：

```text
exports/
  v7_run_<timestamp>_<signature>/
    export_config.json
    export_result.json
    full/
      <mode>/<scale>/<dataset>/layer_4/{0,1,2,3}/
      <mode>/<scale>/manifest.jsonl
      <mode>/<scale>/summary.json
    sampled/
      pure_bg_keep_<ratio>_seed_<seed>/
        <mode>/<scale>/<dataset>/layer_4/{0,1,2,3}/
        <mode>/<scale>/manifest.jsonl
        <mode>/<scale>/window_index.jsonl
        <mode>/<scale>/training_index.jsonl
        <mode>/<scale>/training_stats.json
        <mode>/<scale>/summary.json
```

`full` 保留全部窗口，只用于验证、测试、真实推理和完整空间可视化。`sampled` 才应用训练采样策略，只用于训练。不能使用 Sampled 计算代表真实分布的测试指标。

### 2. 纯背景采样

“纯背景跳过”是采样策略，不是新的聚合模式。

窗口内所有具有原图真实有效面积的基础格都为 `0` 时，才是纯背景。Padding 面积不参与判定。只要存在一个有效的 `1/2/3` 基础格，即使某个面积阈值模式最终把窗口聚合为 `0`，该窗口仍保留。

默认纯背景保留率是 `0%`。保留率和随机种子可以修改。采样按“材质 × 尺度”独立进行，并使用稳定哈希，因此：

- 相同输入、比例和种子可复现相同结果。
- 同一窗口在不同聚合模式中的保留决定一致。
- 不同材质不会互相挤占纯背景配额。

训练时过滤纯背景能够降低 `0` 类主导程度；推理面对未标注新图时不能使用人工标签过滤，仍需扫描所有窗口。

### 3. 四种聚合模式

#### 安全优先 `safety_first`

阈值为 `P_cloth=0.25`、`P_multi=0.30`、`P_wrinkle=0.15`。少量多层或褶皱即可提升窗口风险。

- 实验影响：标签 `2/3` Recall 通常提高，Precision 通常下降。
- 检测影响：容易将“以单层为主、仅含少量多层”的区域预测为 `2`；容易将“多层无褶皱为主、仅含少量褶皱”的区域预测为 `3`。
- 用途：机械臂禁止操作区、减速区、风险掩码。

#### 平衡 `balanced`

阈值为 `P_cloth=0.50`、`P_multi=0.50`、`P_wrinkle=0.30`。

- 实验影响：Macro-F1 和 Balanced Accuracy 通常比安全优先更均衡。
- 检测影响：边界上的少量类别不会轻易升级，但面积较小的真实多层或褶皱可能被预测为 `1/2`。
- 用途：模型训练、尺度比较和常规验证的面积阈值基准。

#### 精度优先 `precision_first`

阈值为 `P_cloth=0.70`、`P_multi=0.70`、`P_wrinkle=0.50`。

- 实验影响：标签 `2/3` Precision 通常提高，Recall 通常下降。
- 检测影响：容易将布料边缘预测为 `0`，将混合的单层/多层区域预测为 `1`，将小范围褶皱预测为 `2`。
- 用途：筛选内部类别更纯的候选操作区。

#### 标签优先级 `risk_priority`

只统计真实有效面积，只要窗口内出现非背景标签，就取最高风险标签 `3 > 2 > 1 > 0`。

- 实验影响：标签 `2/3` Recall 往往最高，但粗尺度越大，标签 `1/2` 越容易被升级，Precision 和校准可能下降。
- 检测影响：容易将“绝大部分为标签 `1`、仅一个基础格为 `3`”的整个粗窗口预测为 `3`。
- 用途：保守风险覆盖。它不应代替精确的褶皱中心定位。

不同聚合模式定义了不同的目标标签，不能混入同一个训练集。若修改面积阈值，输出模式名变为 `custom`，实际阈值写入清单。

### 4. 平方根软平衡

纯背景过滤后，v7 不删除 `1/2/3`，也不复制 PNG。每个“材质 × 尺度 × 类别”组内计数为 `n`，训练索引使用：

```text
raw_weight = 1 / sqrt(n)
```

所有样本权重归一化为均值 `1`，默认上限为 `5.0`，截断后再次归一化。`training_index.jsonl` 每行记录：

```text
sample_id
relative_path
image_id
dataset
label
kernel
stride
sampling_weight
hierarchical_targets
is_pure_background
```

训练端应使用 `sampling_weight` 构造加权采样器，并限制同一 batch 内同一 `image_id` 最多出现一个窗口，减少重叠窗口造成的相关性。

`training_stats.json` 记录过滤前/后类别计数和先验、实际加权目标分布、Balanced Softmax 类别计数、材质分组统计、权重上限和种子。

推荐默认实验是“平方根采样 + Balanced Softmax”，但必须与自然采样、单独平方根采样、单独 Balanced Softmax 做消融。若标签 `1` 经常被预测为 `2/3`，说明双重校正可能过强，应先移除其中一种校正，而不是继续增加少数类权重。

### 5. 层级训练目标

四分类标签同时映射为三个条件任务：

| 标签 | cloth | multi | wrinkle |
|---|---:|---:|---:|
| `0` | 0 | -1 | -1 |
| `1` | 1 | 0 | -1 |
| `2` | 1 | 1 | 0 |
| `3` | 1 | 1 | 1 |

`-1` 表示不适用，训练时作为 `ignore_index`。模型可保留四分类 `class_head`，并增加 `cloth_head`、`multi_head`、`wrinkle_head`。v7 只导出这些目标，不包含模型训练程序。

### 6. 空间复原与预测可视化

启动 `multiscale_visualizer.exe`，选择一个 `v7_run_*` 目录，再选择 Full/Sampled、聚合模式和尺度。工具支持：

- 浏览原图、真值、预测、差异、覆盖范围和跳过区域。
- 从 `window_index.jsonl` 恢复所有候选窗口，包括没有 PNG 的纯背景窗口。
- 加载预测 JSONL。
- 对重叠窗口使用置信度加权投票或最高风险融合。
- 将缺失预测显示为 unknown，不自动当作背景。
- 原绝对路径失效时，使用“原图根目录”按 `dataset/source_relative_path` 重新定位。
- 保存当前叠加结果为 PNG。

标准预测 JSONL 每行格式：

```json
{
  "sample_id": "image_r0000_c0000_k2_s1",
  "predicted_label": "2",
  "confidence": 0.83,
  "probabilities": {"0": 0.02, "1": 0.12, "2": 0.83, "3": 0.03}
}
```

置信度加权投票适合常规分类图；最高风险融合适合机械臂风险区。跳过区域只是训练时未裁剪，不代表推理时可以忽略。

### 7. 实验要求

固定相同原图级数据划分和 Full 验证集，至少比较：

```text
A. 自然采样 + Cross Entropy
B. 纯背景过滤 + Cross Entropy
C. 平方根采样 + Cross Entropy
D. 自然采样 + Balanced Softmax
E. 平方根采样 + Balanced Softmax
F. 层级多头 + 平方根采样 + Balanced Softmax
```

指标至少包括 Accuracy、Macro-F1、Balanced Accuracy、每类 Precision/Recall/F1、混淆矩阵、标签 `2/3` 的 PR-AUC、每材质指标和校准误差。重点查看：

- `3 → 2/1`：褶皱漏检。
- `2 → 1`：多层漏检。
- `1 → 2/3`：重平衡过度导致风险误报。
- `0 → 1/2/3`：背景负样本不足导致误报。

训练和测试必须按原图或视频序列划分，不能把同一原图的重叠窗口分到不同数据子集。
